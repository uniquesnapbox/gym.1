## 🎓 HOW IT WORKS

### Booking Flow
```
User fills form → JavaScript validates → 
Creates WhatsApp message → Opens wa.me link → 
User's WhatsApp opens → Pre-filled message → 
User sends → You receive on +91 7099481497
```

### Animation Flow
```
Page loads → Intersection Observer watches sections → 
User scrolls → Section enters viewport → 
Triggers fade-in class → CSS animation plays → 
Section visible with smooth fade
```

### Responsive Design
```
Desktop (>992px) → 3-column layouts
Tablet (768-992px) → 2-column layouts
Mobile (<768px) → 1-column stacked layouts
```
