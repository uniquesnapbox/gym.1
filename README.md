## 🔧 Customization

### Changing Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #FFB800;  /* Gold */
    --secondary-color: #000000; /* Black */
    --accent-color: #FFA500;   /* Orange */
}
```

### Adding New Pages
1. Copy any existing HTML file
2. Update the navigation active class
3. Add your content
4. Link in the navigation menu

### Changing Images
Replace images in `New folder/` with your own, keeping the same filenames.
